1. OBJECTIF DU PROJET
Passer d'un site statique hébergé sur GitHub Pages à une architecture
serveur professionnelle (Node.js + Express) avec un nom de domaine
personnalisé, un service d'envoi d'emails et une indexation Google.

2. NOUVELLE ARCHITECTURE TECHNIQUE
- Serveur : Node.js avec Express.js
- Hébergement : Render (Plan gratuit, Web Service)
- Nom de domaine : virttech.site (acheté chez Namecheap)
- Emails : SendGrid (via clé API et domaine authentifié)
- Base de données : Aucune pour l'instant (stockage des emails en local)

3. STRUCTURE DU PROJET
📁 virt_tech/
   ├── 📄 server.js            (Serveur Express)
   ├── 📄 package.json         (Dépendances)
   ├── 📄 .env                 (Clés secrètes - NE PAS PARTAGER)
