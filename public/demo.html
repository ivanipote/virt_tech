Formation : Arborescence et Liaison (7 Nov 2026)

📁 C'est quoi un dossier ?

Un dossier, c'est comme une boîte, un sac, ou un lieu où l'on range tout ce dont on a besoin pour atteindre un objectif. En informatique, c'est l'espace où l'on stocke les fichiers d'un projet.

🌳 C'est quoi l'arborescence ?

L'arborescence, c'est la structure que tu vois dans ton dossier de travail. En un mot, ce sont tous les fichiers et dossiers qui constituent ton projet, organisés de manière logique.

🎯 Comment choisir une bonne arborescence ?

Tout dépend du projet. Si ton projet est uniquement du front-end (pas de backend/serveur), tu as la liberté de structurer tes fichiers comme tu veux. Voici des exemples concrets :

📂 Exemple 1 : Projet Minimal (Tout à la racine)

C'est le plus simple pour débuter. Idéal pour un site vitrine statique.

STRUCTURE
Mon-Ecole/ ├── index.html ├── contact.html ├── style.css ├── script.js └── images/ ├── logo.png └── banniere.jpg

📂 Exemple 2 : Projet Structuré (Avec sous-dossiers)

Quand le projet grandit, on sépare le CSS, le JS et les médias dans des dossiers dédiés.

STRUCTURE
Mon-Portfolio/ ├── index.html ├── a-propos.html ├── css/ │ ├── style.css │ └── responsive.css ├── js/ │ └── script.js └── assets/ ├── images/ │ └── profil.jpg └── videos/ └── presentation.mp4

🔗 Lier les fichiers entre eux

Une fois l'arborescence créée, il faut dire au fichier HTML où trouver le CSS et le JS.

1. Lier le CSS (dans la balise <head>) :

HTML
<link rel="stylesheet" href="style.css">

Si le CSS est dans un dossier (ex: css/style.css), on précise le chemin :

HTML
<link rel="stylesheet" href="css/style.css">

2. Lier le JS (juste avant la fermeture de </body>) :

HTML
<script src="script.js"></script>

💡 Le secret des chemins

La règle d'or : mettre le nom du sous-dossier, un slash, jusqu'à atteindre le fichier cible.

Exemple : si ton image est dans assets/images/logo.png, tu écriras dans ton HTML :

HTML
<img src="assets/images/logo.png" alt="Logo">
